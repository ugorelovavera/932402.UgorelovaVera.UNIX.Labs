# 932402.UgorelovaVera.UNIX.Lab2

Лабораторная 2 по курсу "Операционная система UNIX" ИПМКН ТГУ, 2026 год
Содержит набор файлов для запуска конкурентных контейнеров, работающих с общим Docker-томом

В томе несколько контейнеров одновременно создают и удаляют файлы с именами 001, 002, 003 и т. д. Выбор свободного имени и создание файла выполняются как атомарная операция под flock на служебном файле .lock, что исключает race condition. В каждый файл записывается идентификатор контейнера и порядковый номер созданного этим контейнером файла.

Контейнер работает в бесконечном цикле: под блокировкой находит первое свободное имя, создаёт файл с содержимым "ID SEQ" и дописывает строку в лог .log, затем ждёт одну секунду, под блокировкой удаляет файл и снова ждёт секунду. Критическая секция короткая — задержки находятся вне flock.

Для проверки корректности используется скрипт check, который читает лог .log и проверяет: все ли N контейнеров работали, нет ли пробелов в нумерации 001..MAX, идёт ли SEQ по каждому ID без пропусков и повторов, нет ли дублей (ID, SEQ). Скрипт runtest запускает N контейнеров на T секунд, вызывает check, останавливает контейнеры и очищает файлы, оставляя лог для просмотра следующим запуском.

Тесты проводятся с 1, 10 и 50 экземплярами контейнера. Во всех случаях check показывает OK — это доказывает, что flock исключает race condition при одновременной работе нескольких контейнеров с общим томом.

Структура:
- worker.sh — POSIX Shell скрипт контейнера
- Dockerfile — образ workerlab2 на базе alpine с util-linux для flock
- runtest — запуск теста на N контейнеров, T секунд
- check — валидатор по логу /shared/.log
- .dockerignore — исключения для контекста сборки
